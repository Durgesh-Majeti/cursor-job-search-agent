# Session workspace placeholders

Replace these files with your real materials, then run the `setup` skill so
they are parsed into `host.kv`. Until then, tools may report `placeholder: true`.

| File | Purpose |
| --- | --- |
| `profile.placeholder.json` | Contact, targets, constraints |
| `experience-library.placeholder.json` | STAR bullets + skills (facts only) |
| `resume.placeholder.md` | Source resume text for parsing |

Do not invent employers, dates, or metrics when filling these in.
