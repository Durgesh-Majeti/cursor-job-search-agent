# Cover letter

## Steps

1. Skip unless the posting requires a letter or the user asks.
2. Pull job + profile + tailored resume facts.
3. Write a short letter (≤250 words): why this role, 1–2 grounded achievements, close.
4. Save path on the application (`artifactPaths.coverLetter`).

## Rules

- Facts only — same as tailor-resume.
- No flattery filler; no invented company research claims.
